### Axisymmetric SHPB Modeling with PINN (ANSYS + TensorFlow)

- Developed axisymmetric elastodynamic model governed by **Navier–Cauchy equations**  
- Simulated high strain-rate loading using ANSYS Explicit Dynamics  
- Extracted boundary time histories and used them as constraints in a **Physics-Informed Neural Network (PINN)**  
- Reconstructed full spatiotemporal displacement fields u(r, x, t)

**Outcome:**  
Achieved PDE-consistent field reconstruction matching FEA results, enabling insight into internal wave propagation behavior.
